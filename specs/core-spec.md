## Project: Daily Fun Fact CLI

### Goal

A CLI tool that prints a fun fact generated by an LLM.

### Requirements

- CLI command: `funfact`
- Prints a fun fact under 200 characters
- Uses an LLM to generate the fact
- Output must be in English
- Output must not be empty

### Tech Stack

- TypeScript
- Node.js
- Jest (testing)
- npm (package manager)

### Testing

- Should return a string
- Length < 200 characters
