# CLAUDE.md

## Project Overview

Daily Fun Fact CLI — a spec-driven project with two tiers:

1. **Workflow CLI** (meta-tool): Transforms specifications into working code via a pipeline (`init` → `code` → `feature` → `debug`)
2. **Daily Fun Fact CLI** (target): A CLI tool (`funfact`) that prints an LLM-generated fun fact under 200 characters

Currently at the **specification stage** — no generated source code exists yet.

## Tech Stack

- **Language**: TypeScript
- **Runtime**: Node.js
- **Testing**: Jest
- **Package Manager**: npm

## Project Structure

```
specs/
├── core-spec.md                # Source of truth for the target CLI
├── new-features/*.md           # Pending feature requests
├── features/*.md               # Generated feature specs
└── generated-new-features/     # Archived processed requests

workflow/
└── specs/
    ├── core-spec.md            # Workflow CLI specification
    └── commands/
        ├── init.md             # Bootstrap derived specs
        ├── code.md             # Generate source code & tests
        ├── feature.md          # Add features via pipeline
        └── debug.md            # Debug failing code/tests

derived-spec/                   # Generated by `workflow init`
src/                            # Generated by `workflow code`
tests/                          # Generated by `workflow code`
```

## Spec-Driven Workflow

The single source of truth is `specs/core-spec.md`. All changes flow through specs first:

```
specs/core-spec.md → workflow init → derived-spec/ → workflow code → src/ + tests/
```

- `derived-spec/` files are regenerated, never manually edited
- Running `init` → `code` on the same specs must produce identical output
- Features are added incrementally through the `feature` pipeline

## Key Conventions

- Specs define behavior; code is derived from specs
- The `--force` flag is required to overwrite existing generated output
- Each workflow command validates preconditions and errors clearly on failure
- Feature requests go in `specs/new-features/`, processed ones move to `specs/generated-new-features/`
